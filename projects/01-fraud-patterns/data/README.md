# Data

Raw data files live in this folder on my computer and are not
committed to GitHub.

## Dataset: PaySim

Synthetic mobile-money transactions with a fraud label, generated by
the PaySim simulator from a sample of real transaction logs. The
Kaggle version is scaled down to one quarter of the original.

| File | Source | Downloaded | Licence |
|------|--------|------------|---------|
| _[PS_20174392719_1491204439457_log]_ | https://www.kaggle.com/datasets/ealaxi/paysim1 | _[11/16/2026]_ | _[CC BY-SA 4.0]_ |

## Why this dataset

- The columns are readable (transaction type, amount, balances), so
  patterns can be explained in plain language.
- It was chosen over the ULB credit card dataset, which has real data
  but anonymised columns (V1 to V28).

## Known limits

- Synthetic: findings describe the simulation, not real customers.
- Time is a step counter (1 step = 1 hour, 744 steps), not calendar
  dates.
- Balance columns are unreliable for fraud rows.

## To reproduce

1. Sign in to Kaggle (free account).
2. Open the source link above and download the dataset.
3. Unzip the CSV file into this folder.
